更新日志 ​

[2.1.10] 2026-08-23 ​

⚠️ 不兼容变更 ​

  • 💥 wechatWork 步骤移除 picUrl 与 topImg 两个参数：图文图片改名为 cardImageUrl（对齐官方字段 card_image.url，picUrl 是钉钉 link 消息的字段名），topImg 承载的是飞书上传后的 image key，企业微信无法渲染，仅在 key 恰好是 http 地址时才生效。用到这两个参数的流水线需要改写为 cardImageUrl，否则步骤会因参数不存在而报错。飞书与钉钉步骤的 topImg、picUrl 不受影响。
  • ⬆️ Jenkins 基线升级至 2.555.3，详见下方 Build / Dependency。

⭐ Features ​

  • ✨ 三个平台的卡片内容行均支持自定义：lark、dingTalk、wechatWork 步骤新增 cardFields 参数，每行可配置 keyname、value 与可选的跳转 url，三个字段都支持环境变量展开。企业微信渲染为结构化内容行（超出官方 6 行上限的部分自动丢弃），飞书与钉钉卡片渲染为 **标签**: 内容 正文行。
  • ✨ lark 步骤新增 ats 与 atAll 参数，此前 Pipeline 无法通过参数 @ 人，只能在 text 里手写 <at> 标签。
  • ✨ 钉钉新增 FEED_CARD 图文列表消息类型（feedCardLinks），以及 actionCard 的 hideAvatar 隐藏头像选项。
  • ✨ 企业微信卡片新增引用区块 quoteTitle / quoteText / quoteUrl（quote_area），并接通此前未生效的 sourceDesc（source.desc）自定义头部来源文案。
  • ✨ 企业微信卡片头部来源图标支持自定义：wechatWork 步骤新增 sourceIconUrl（source.icon_url），此前该图标硬编码为 Jenkins 图标，无法改成自己团队的标识（#288）。

🔨 Build / Dependency ​

  • ⬆️ 运行要求变更：Jenkins 基线升级至 2.555.3（此前为 2.541.x），构建改用 Java 21 工具链。低于该版本的 Jenkins 无法安装本次更新，升级前请先确认控制器版本。
  • ⬆️ 同步升级 Jenkins Plugin Parent 与 Jenkins BOM。

🧪 Tests ​

  • 🧪 补齐消息发送链路的测试护栏：新增飞书 / 钉钉 sender 与 step 的报文基线测试、共享 HTTP 层、机器人配置测试按钮、机器人 Job 绑定服务，以及协议 × 消息类型支持矩阵的穷举校验；测试框架迁移至 JUnit 5。

♻️ Refactor ​

  • ♻️ 重构消息模型为三层结构（构建上下文、跨平台渲染意图、平台独有字段），MessageSender 泛型化，分发器按消息类型路由并校验平台支持矩阵，降低跨平台字段耦合。
  • ♻️ 飞书 IMAGE、SHARE_CHAT、POST 改为从平台字段读取，不再把图片 key、群名片 id、富文本结构塞进共享文本字段传递（富文本此前还要经历一次 JSON 序列化再反序列化）。
  • ♻️ 构建信息行（任务名称、任务编号、构建状态、构建用时、执行人）收敛为唯一定义，Markdown 正文与各平台卡片均由其派生，不再各写一份；同时移除用正则反解自身 Markdown 的死代码。
  • ♻️ 三个 Pipeline 步骤的公共逻辑上提，语言、@ 人变量展开、默认按钮行为统一。

🐛 Fixes ​

  • 🩹 修复自定义模板中 ${JOB_STATUS} 不跟随机器人「消息语言」设置的问题：内置卡片行按机器人语言渲染，而该变量此前使用 Jenkins 进程默认语言，同一张卡片会中英混排。
  • 🩹 修复 Pipeline 环境变量在并发构建间相互串用的问题，环境快照改为绑定到具体构建（#283）。
  • 🩹 修复钉钉整体跳转 actionCard 跳转链接从未生效的问题：字段名按官方自定义机器人 API 修正为 singleURL（原为 singleUrl，钉钉会直接忽略）。
  • 🩹 修复钉钉单按钮卡片丢失安全关键词的问题，配置了「自定义关键词」的机器人此前会拒收该类消息。
  • 🩹 修复钉钉卡片默认按钮的判断条件颠倒：默认的「更改记录 / 控制台」按钮此前只在设置 singleTitle（即按钮会被忽略）时才补充。
  • 🩹 修复 lark 与 dingTalk 步骤忽略机器人「消息语言」配置的问题，此前仅企业微信步骤会读取该设置。
  • 🩹 修复 dingTalk 步骤的 ats 不做环境变量展开的问题。
  • 🩹 修复 failOnError: false 无法拦住发送过程中意外异常的问题，此前任何运行时异常都会导致构建失败，与该开关语义相反。
  • 🩹 平台专属步骤指向其他协议的机器人时（如 wechatWork 指向飞书机器人），改为输出可读的错误提示并指明应使用的步骤，此前会抛出 ClassCastException 到构建日志。
  • 🩹 修复企业微信卡片图文位置始终显示 Jenkins 图片的问题：卡片图片现在优先取用户配置的 cardImageUrl，仅当未配置或非可访问 HTTP(S) 地址时才回退默认图。
  • 🩹 恢复企业微信卡片在有结构化构建字段时不重复渲染正文块的行为，避免正文与内容行重复展示。
